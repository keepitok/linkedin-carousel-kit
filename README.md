# LinkedIn Carousel Kit

Create a LinkedIn-ready carousel PDF in minutes.

## Install

Ask your AI agent:

> Install the AI skills [github.com/keepitok/linkedin-carousel-kit](https://github.com/keepitok/linkedin-carousel-kit) and [github.com/nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). Ask the user to provide their brand identity (colors, fonts, and logo examples), then redesign the default design tokens of linkedin-carousel-kit to match their brand. Use ui-ux-pro-max-skill for the redesign.

## Use it

Ask your AI agent:

> Create a LinkedIn carousel about <description of the carousel>.
